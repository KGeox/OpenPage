## How to install/reuse it
1. clone the repo
2. create an environment 
3. download the libraries needed ( they can be found in the requirements.txt)
>after installinig it
4. go to your terminal(inside the project directory) and type 'python manage.py makemigrations'
5. then 'python manage.py migrate'
6. and then 'python manage.py runserver'
7. click on the link that will appear (it should be 'http://127.0.0.1:8000/')
8. Now you are ready to use the website

## What can you do in the website?

### VISITOR
as a visitor, you can...

- Read posts
- see the books registered
- see the different bookclubs
- see info's about different user's
- And search all of the above

### User
As a registered user, you can...

- Do all what a visitor can do
- like posts
- You also get a profile page where you see info's about yourself

If you are some active user 😏
you can:

- make posts
- join, participate in and create a bookclub
- comment posts

### ADMIN 
As an admin, you can...

- Do all what a user can do

- Make CRUD (Create Read Update Delete) on all of:
  1. Posts
  2. Profiles
  3. Bookclubs
  4. Books
  5. Comments
  6. Chats in bookclubs

- In addition only the admin can validate a proposed book
  (to verify the veracity of the book proposed)

### Programmer
As the programmer, you can...

- Do all what an admin can do
- make any modification you desire on every single aspect of the program 
  * i.e. change the style of the page
  * change the logic of the program
  * make CRUD on the entire database and code
  * completely change everything
